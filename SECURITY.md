# Security reports

Security-sensitive changes must preserve permission checks, plugin/service
ownership, and cleanup of only the attachments registered by rzVault.

If GitHub private vulnerability reporting is enabled for this repository, use
its private report form. Otherwise, open an issue requesting a private contact
without posting exploit details, credentials or player data. No private email
address is advertised by this project.

Include the rzVault, Paper and Java versions, provider plugins, a minimal
reproduction and sanitized relevant errors. Ordinary compatibility/configuration
problems can be reported through a normal issue.
