# Публикация на GitHub

1. Создать пустой публичный репозиторий `ThreadLeak/rzVault`. Готовые README и
   лицензии уже находятся в проекте; добавлять другие шаблоны поверх не требуется.
2. Использовать корнем репозитория новую папку `rzVault`, в которой находятся
   `pom.xml`, `src`, `.github`, `.mvn`, лицензии и wrapper. Соседние проекты,
   старую `Vault-master`, кэши, бэкапы и `target` в коммит не включать.
3. После загрузки дождаться workflow Build для Linux и Windows. Он ещё не
   выполнялся на GitHub во время локальной подготовки.
4. Создать тег `v1.0.1` и релиз к нему. Приложить устанавливаемый JAR, source JAR,
   полный ZIP исходников и SHA256SUMS из подготовленного комплекта релиза.
5. На сервер устанавливается только `rzVault-1.0.1.jar`. Должен оставаться один
   Vault-мост; `*-sources.jar` и ZIP — материалы разработчикам, не плагины.

Если имя или владелец репозитория отличаются, сначала обновить ссылки в pom.xml,
plugin.yml и README и собрать релиз заново. Исходники и бинарник релиза должны
соответствовать друг другу. Для следующего изменённого выпуска увеличить версию.
